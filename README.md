# Сравнение self-hosted LLM-гейтвеев

LiteLLM, Bifrost и new-api на одном сервере, в трёх режимах: голый прокси,
прокси с учётом расходов в БД и прокси с виртуальными ключами и бюджетами.

Что меряется:

- задержка до первого токена (по самому токену, а не по заголовкам ответа);
- пропускная способность и память, с контрольным прогоном без гейтвея;
- поведение при 429, 503, таймауте и обрыве стрима, фолбэк на второй апстрим;
- что остаётся в логах и базе: ключи провайдера, клиентские ключи, промпты.

Стенд и инструкция — в [stand/](stand/README.md), наблюдения по ходу
сборки — в [nahodki.md](nahodki.md).
