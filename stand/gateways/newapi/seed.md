# Настройка new-api

Мастер первого запуска создаёт администратора, канал и токен. Всё это
доступно через HTTP API самого new-api, поэтому шаг автоматизирован:

```bash
./run.sh up newapi bare
./gateways/newapi/seed.sh
```

Скрипт создаёт администратора `admin` со случайным паролем
(`gateways/newapi/data/admin.txt`), канал `mock-a` на мок-апстрим и токен
`bench` (`gateways/newapi/data/api-key.txt`). Каталог `data/` в `.gitignore`.
Повторный запуск ничего не дублирует.

Для статьи нужен скриншот панели: войди под `admin` с паролем из `admin.txt`
и сними окно с каналом и токеном. На VDS панель наружу не открывай, пробрось
туннель: `ssh -L 3000:127.0.0.1:3000 root@АДРЕС_СЕРВЕРА`.

## Если скрипт не сработал — вручную

1. Поднять гейтвей:

   ```bash
   ./run.sh up newapi bare
   ```

2. Открыть `http://127.0.0.1:3000`. Если работаешь на VDS, не открывай порт
   наружу — пробрось туннель с ноутбука:

   ```bash
   ssh -L 3000:127.0.0.1:3000 root@АДРЕС_СЕРВЕРА
   ```

3. Пройти мастер, создать администратора. Пароль придумай свой,
   в репозиторий его не кладём.

4. Добавить канал на мок-апстрим: раздел «Каналы» → создать.

   | Поле | Значение |
   |---|---|
   | Тип | OpenAI-совместимый (custom / OpenAI) |
   | Адрес | `http://127.0.0.1:9000` |
   | Ключ | `sk-upstream-SENTINELUP7f3a2b` |
   | Модели | `mock-fast`, `mock-realistic` |

   Нажать «Тест» — канал должен ответить успешно.

5. Создать токен в разделе «Токены», скопировать его и положить в файл:

   ```bash
   echo 'ВСТАВЬ_ТОКЕН' > gateways/newapi/data/api-key.txt
   ```

6. Проверить, что ключ работает:

   ```bash
   curl -s http://127.0.0.1:3000/v1/chat/completions \
     -H "Authorization: Bearer $(cat gateways/newapi/data/api-key.txt)" \
     -H 'Content-Type: application/json' \
     -d '{"model":"mock-fast","messages":[{"role":"user","content":"привет"}]}' | jq .usage
   ```

   Должен прийти `{"prompt_tokens":3,"completion_tokens":64,"total_tokens":67}`.

7. Сделать скриншот окна с каналом и токеном — пойдёт в статью как
   иллюстрация к разделу про ручную настройку.

Дальше `./run.sh all <профиль>` подхватит new-api сам. Без файла с ключом
он его пропустит и напишет об этом.
